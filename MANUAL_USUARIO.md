# 📘 Manual de Usuario - MiniMarket Pro

¡Bienvenido al manual oficial de **MiniMarket Pro**! Este documento te guiará a través de todas las funcionalidades del sistema para que puedas gestionar tu inventario y ventas de manera eficiente.

---

## 🚀 1. Inicio de Sesión
Para acceder al sistema, debes ingresar tus credenciales autorizadas:
1. **Usuario**: Tu nombre de usuario asignado.
2. **Contraseña**: Tu clave de acceso personal.
3. Haz clic en **"Ingresar al sistema"**.

> [!NOTE]
> Si el sistema no conecta, verifica que el servicio de base de datos esté activo o contacta al administrador.

---

## 📊 2. Dashboard (Panel Principal)
Al ingresar, verás un resumen ejecutivo de tu negocio:
- **KPIs**: Total de productos con stock, ventas del día, cantidad de transacciones y compras realizadas.
- **Gráfico de Ventas**: Visualización de los ingresos de los últimos 7 días.
- **Actividad Reciente**: Historial rápido de las últimas ventas y compras registradas.
- **Alertas de Stock Bajo**: Lista de productos que están por debajo de su stock mínimo.

---

## 📦 3. Gestión de Inventario
### 3.1 Productos
En el módulo de **Productos**, puedes:
- **Registrar Nuevo**: Haz clic en el botón "+" e ingresa código de barras, nombre, categoría, unidad de medida y precios.
- **Editar**: Modifica la información de un producto existente.
- **Control de Stock**: Visualiza el stock actual en tiempo real.
- **Filtrar**: Busca productos por nombre, código o categoría.

### 3.2 Categorías
Organiza tus productos por tipos (ej. Bebidas, Lácteos, Limpieza). Cada categoría puede tener un color distintivo para facilitar su identificación en el punto de venta.

---

## 💰 4. Módulo de Ventas (POS)
Este es el corazón de la operación diaria:
1. **Selección de Productos**: Busca por código de barras (usando escáner) o nombre.
2. **Carrito de Compras**: Ajusta las cantidades de los productos seleccionados.
3. **Procesar Pago**:
   - Selecciona el método de pago (Efectivo, Tarjeta, Yape/Plin).
   - Ingresa el monto pagado por el cliente.
   - El sistema calculará automáticamente el vuelto.
4. **Finalizar**: Se registrará la venta, se descontará el stock y se generará un comprobante.

---

## 🛒 5. Compras e Ingresos
Para reponer stock, utiliza el módulo de **Compras**:
1. Haz clic en **"Nueva Compra"**.
2. Ingresa el número de documento de referencia (boleta/factura del proveedor).
3. Agrega los productos y las cantidades recibidas.
4. Indica el costo unitario de compra.
5. Al guardar, el stock se incrementará automáticamente y se actualizará el historial de precios.

---

## 📈 6. Reportes y Estadísticas
Obtén una visión detallada del rendimiento:
- **Ranking de Productos**: Cuáles son los productos que generan más ingresos.
- **Ingresos Mensuales**: Comparativa de ventas mes a mes.
- **Kardex**: Historial detallado de cada movimiento (entrada/salida) de cada producto para auditorías.

---

## ⚙️ 7. Configuración y Sincronización
### 7.1 Datos del Negocio
Personaliza los datos que aparecen en tus comprobantes: RUC, Razón Social, Dirección y Teléfono.

### 7.2 Sincronización (Multi-Sede)
Si tu negocio tiene varias sucursales:
- **Estado de Sincronización**: Verifica cuántas ventas locales están pendientes de enviarse a la sede central.
- **Botón Sincronizar**: Envía los datos locales al servidor central de forma manual.
- **Configuración de Sede**: Define el código de tu sucursal y la URL del servidor central.

---

## 🛠️ 8. Mantenimiento de Datos
En la sección de **Base de Datos**, puedes realizar tareas de mantenimiento:
- **Optimizar**: Compacta la base de datos para mejorar la velocidad.
- **Backup**: Crea una copia de seguridad manual de toda tu información.
- **Explorar Archivo**: Accede directamente a la ubicación física de la base de datos (solo para soporte técnico).

---

## 💡 Consejos de Uso
- **Escáner de Barras**: Asegúrate de que el cursor esté en el campo de búsqueda antes de escanear.
- **Cierre de Caja**: Revisa el "Resumen de Hoy" en el módulo de ventas antes de terminar tu turno.
- **Seguridad**: Nunca compartas tu contraseña y asegúrate de cerrar sesión al retirarte de tu puesto.
